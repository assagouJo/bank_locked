# 🏦 Simulation Bancaire — Sensibilisation Anti-Phishing

Interface bancaire simulée à but **pédagogique** pour sensibiliser aux arnaques "compte bloqué".

## 🎯 Objectif
Démontrer visuellement comment un faux site bancaire peut paraître réaliste, afin d'apprendre à reconnaître les signaux d'alerte.

## ⚠️ Avertissement
Ce projet est **100 % pédagogique**. Aucune donnée n'est collectée, envoyée ou stockée. Aucun lien réel n'existe.
